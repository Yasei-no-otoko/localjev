# Native JSON-output diagnosis

The extra quote is generated by the native decoder. All three saved HTTP failures reproduce token-for-token in the standalone decoder with the same model, input IDs and seeds. Switching Flash Attention (FA) and prompt KV-cache settings changes the forward logits and subsequent denoising trajectory. The observed behavior is sensitive to those inference paths; these experiments do not establish faulty model weights or identify a faulty kernel.

This report covers three selected short-context failures: `ag_news:test:7375`, `sst5:test:104`, and `ag_news:test:6369`. It is not a complete benchmark or evidence of universal JSON validity.

| Entropy accumulation | FA | Prompt KV cache | Valid JSON/schema | Steps by case |
|---|---|---|---:|---|
| Sequential FP32 | on | on | 0/3 | 5, 10, 5 |
| Sequential FP32 | on | off | 2/3 | 5, 7, 7 |
| FP64 accumulation | on | on | 0/3 | 5, 10, 5 |
| FP64 accumulation | on | off | 2/3 | 5, 7, 7 |
| FP64 accumulation | off | on | 3/3 | 9, 9, 7 |
| FP64 accumulation | off | off | 2/3 | 7, 11, 6 |

Validity requires the expected probability-array schema, finite values in [0,1], and a sum of 1 within tolerance. The exact empty thought prefix is removed as by chat parsing; generated JSON is not repaired. Validity is separate from gold correctness.

The baseline contains eight rows, cache isolation six, FP64 with FA on six, and FP64 with FA off six. All 26 input token arrays match fresh CPU HF tokenization with the native BOS convention (448, 428, and 474 tokens), and all seeds match their source cases. The three baseline outputs match the saved HTTP token arrays and content. Repeating AG7375 reproduces its output. Forcing all 48 steps preserves the malformed output in all three cases, so early stopping is not the cause of these failures.

Every matched FA-on output canvas and step count is unchanged after FP64 accumulation (6/6). With FA on, disabling the prompt cache makes AG7375 and SST104 valid; AG6369 remains malformed. With FA off and the cache on, the three selected cases are valid. With both FA and cache off, AG7375 is malformed. Neither toggle alone is demonstrated to be a general fix.

The position-4 probe compares token `14937` (`{"`) with token `236782` (`{`). The table gives the first-step raw-logit difference, quote-token minus brace-token; a positive value favors the first token. All 88 probe-step comparisons agree with the recorded canvas token.

For AG7375 with FA on, cache-off changes the margin from +0.670446 at step 0 to -2.509892 at step 1; the final canvas differs from cache-on at exactly position 4, with unchanged probabilities. The compact opening token is not intrinsically erroneous: AG6369 with FA off emits valid compact JSON beginning with that same token. Invalidity requires considering its continuation.

An independent CPU fixture confirms a separate numerical defect: sequential FP32 accumulation can lose small probability tails across a 262,144-token vocabulary. With an early peak, entropy becomes 0.00491905 instead of the analytical 0.00514881, crossing the 0.005 confidence threshold and accepting 21 positions instead of 20 under the entropy bound. The FP64 normalizer/CDF/entropy fix addresses that defect. The unchanged live FA-on outputs prevent attributing these extra quotes to it. See [checks.json](checks.json) for the analytical and official CPU reference, including the distinction between emulation and compiled tests.

Tokenizer conversion and detokenization are excluded for these outputs: all 262,144 vocabulary IDs and 514,906 merge entries match HF, and HF decoding reproduces the native raw text exactly. The extra quote is already part of token 14937 before HTTP serialization or chat parsing.

The recorded standard model SHA-256 is `0457845b7b56fbc5c651d555eb217399cea77c12cc8efe110ecbfc00bccb8c90`, consistent with the earlier standard-Q8 report; model weights were not rehashed during this audit. [experiment.json](experiment.json) preserves the original matrix-build hashes and timestamps. Later rebuilds changed the current replay executable, server and common library; [summary.json](summary.json) lists recorded and current hashes separately. The two core native libraries and all three recorded fixed source files still match. Historical overwritten executable hashes cannot be independently reverified from the current paths.

The four native stdout JSONL captures are stored with LF line endings for stable Git checkouts. All parsed records were verified unchanged by CRLF-to-LF normalization. The summary retains both the original captured byte hashes and the stored-file hashes; this serialization step does not change any tokens, logit values or metrics.

For reproduction, preserve the ordered input JSONL, model, seeds, 256-token canvas, sampler schedule and per-row cache setting. Precision replay rows explicitly record FA and probe configuration; earlier rows use the original FA-on harness. Compare complete token arrays and raw logits before parsing. Targeted native-kernel comparisons would be needed to establish a specific forward implementation defect.
